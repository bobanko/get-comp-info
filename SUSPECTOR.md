# SUSpector

`SUSpector.exe` — самостоятельная программа для проверки и подготовки пользовательского компьютера перед внешней проверкой.
Она использует то же ядро проверок, что и раздел «Кибербезопасность» в `comp-info.exe`, но не содержит главного окна тулбокса,
базы устройств, сбора записей, синхронизации и облачных страниц.

Проверки выполняются локально. Результаты никуда не отправляются. Действия подготовки явно запускает пользователь;
первое такое действие — отключение синхронизации OneDrive без удаления локальных файлов и настройки учётной записи.
Позже сюда можно добавлять очистку файлов и другие шаги подготовки.

Галочка «Сканировать документы» рядом с кнопкой запуска (включена при каждом запуске программы) позволяет
пропустить долгий поиск ДСК-файлов по дискам: строка проверки остаётся в таблице с пометкой «Пропущено».
Галочка есть и в разделе «Кибербезопасность» comp-info — страница у них общая.

У найденных файлов метки места и число совпадений — в отдельных колонках; колонка меток по ширине самого длинного набора.
Метка `#SupraWeed` (своего цвета) ставится файлам, у которых в пути есть папка со словом «supraweed»: это обычно
сопроводительные письма SupraWeed, их не скрываем, но помечаем. `#Viber` — папки ViberPC и ViberDownloads.

Над таблицей файлов появляются кнопки «Удалить все найденные: корзина · N», «даунлоадс», «телеграм», «WhatsApp», «Viber»,
«Claude» — только для меток, у которых есть хотя бы один файл. Файлы с меткой SupraWeed такие кнопки не удаляют
(подтверждение говорит, сколько пропущено), их можно удалить только по одному.

Кнопки справа в строке запуска (как в VS Code) ставят таблицу файлов под таблицей проверок или рядом с ней.
Выбор сохраняется: в SUSpector.ini как `layout=bottom|right`, в comp-info.ini как `securityLayout`;
для скриншотов есть `--layout right`.

Найденный документ можно удалить кнопкой-корзиной в последнем столбце таблицы файлов (или клавишей Delete) после подтверждения.
Удаление безвозвратное, мимо корзины Windows: проверка ищет документы и в корзине. Файл, найденный в корзине (`$R…`),
удаляется вместе со своей записью `$I…`. Итог проверки показывает число удалённых файлов; когда удалены все найденные,
проверка становится предупреждением с просьбой запустить её снова (в списке не больше 200 совпадений).

## Сборка

```bat
tools\build.BAT
```

Скрипт создаёт в корне два независимых файла одной версии:

- `comp-info.exe` — полный внутренний тулбокс;
- `SUSpector.exe` — отдельное окно для пользователей.

Иконка SUSpector — `app\suspector.ico`, её делает `tools\make-icon.BAT`: размеры от 96 px — из `app\suspector-source.png` (подозрительный взгляд), до 64 px включительно (панель задач, заголовок окна, мелкие значки) — из `app\suspector-small-source.png` (глаз в треугольнике), у которого скрипт убирает чёрный фон со свечением. Картинка окна «О программе» — `app\suspector.png` из того же исходника.
Проверка вёрстки без показа окна:

```bat
SUSpector.exe --theme light --language ru --screenshot suspector.png 700
```

Поддерживаются языки `uk`, `en`, `ru`; без параметра используется язык Windows. Тема по умолчанию также берётся из Windows.
Язык и тема переключаются в нижней панели и сохраняются в отдельный `SUSpector.ini` рядом с программой.
Кнопка «О программе» открывает окно в том же виде, что и в comp-info: картинка, версия, состав проверок, действия подготовки, конфиденциальность, обновление, клавиши и связь с разработчиком (почта копируется по щелчку, сайт, папка программы).
SUSpector не входит в архив обновления основного тулбокса: его можно передавать пользователю как один самостоятельный файл.

## Обновления

Для SUSpector собирается отдельный архив `dist\SUSpector-<версия>.zip`, содержащий только `SUSpector.exe` и `manifest.json`.
GitHub Actions публикует его независимо от внутреннего пакета Comp Info в подписанном релизе по тегу.
Публичный API `/api/suspector` отдаёт только метаданные и этот архив; ключ Comp Info пользователю не нужен,
а получить через него основную программу или данные базы невозможно.

Кнопка «Обновление» в нижней панели проверяет `/api/suspector/latest`, скачивает архив во временную папку Windows,
сверяет SHA-256 архива и файла с `manifest.json` и заменяет именно запущенный exe, даже если браузер сохранил его
как `SUSpector (1).exe`. Старый файл остаётся рядом как `<имя>.exe.old` и удаляется при следующем запуске.

## Страница скачивания

Пользователям даётся ссылка https://comp-info.chagear.top/suspector/ — отдельная публичная страница
(`cloud/public/suspector/`) с описанием программы и кнопкой «Скачать SUSpector.exe».
Кнопка ведёт на `/api/suspector/download`: Worker распаковывает из текущего архива сам `SUSpector.exe`
и отдаёт его как файл, версию страница берёт из `/api/suspector/latest`.

В веб-интерфейсе администратора раздел «Версии программ» показывает версии Comp Info и SUSpector отдельно;
у SUSpector, как и у Comp Info, можно сделать текущей предыдущую версию — её будут скачивать со страницы
и её предложит кнопка «Обновление».

## Cloudflare Access

Пути `/api/suspector/*` (метаданные, архив и exe), `/api/suspector-release` (публикация из GitHub Actions),
`/suspector` и `/suspector/*` (страница скачивания) должны быть открыты без входа, как `/api/client/*` и `/api/release`;
иначе Access отвечает перенаправлением на страницу входа.
