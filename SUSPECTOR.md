# SUSpector

`SUSpector.exe` — самостоятельная программа для проверки и подготовки пользовательского компьютера перед внешней проверкой.
Проверка кибербезопасности есть только здесь: в `comp-info.exe` такого раздела нет (с 21.11.2026), Тулбокс запускают для сбора
сведений и настройки компьютера. Имя компьютера и домен пользователь сам не исправит: при несоответствии SUSpector пишет
в деталях проверки «Чтобы исправить, обратитесь к системному администратору» (администратор исправляет их Тулбоксом;
на Тулбокс SUSpector не ссылается — это программа для пользователей).

Кнопка «Поиск по документам» (Ctrl+F) внизу окна открывает отдельное окно с той же страницей поиска, что и раздел
«Поиск» Тулбокса (`app\wpf\Pages\SearchView`, `app\wpf\SUSpector\SearchWindow.cs`): найти потерянный рабочий файл
по фразе в имени или в тексте документов. Esc останавливает поиск, а если он не идёт — закрывает окно.

Проверки выполняются локально. Результаты никуда не отправляются. Действия подготовки явно запускает пользователь;
первое такое действие — отключение синхронизации OneDrive без удаления локальных файлов и настройки учётной записи.
Позже сюда можно добавлять очистку файлов и другие шаги подготовки.

Галочка «Сканировать документы» рядом с кнопкой запуска (включена при каждом запуске программы) позволяет
пропустить долгий поиск ДСК-файлов по дискам: строка проверки остаётся в таблице с пометкой «Пропущено».

У найденных файлов метки места и число совпадений — в отдельных колонках; колонка меток по ширине самого длинного набора.
Метка `#SupraWeed` (своего цвета) ставится файлам, у которых в пути есть папка со словом «supraweed»: это обычно
сопроводительные письма SupraWeed, их не скрываем, но помечаем. `#Viber` — папки ViberPC и ViberDownloads.

Над таблицей файлов появляются кнопки «Удалить все найденные: корзина · N», «даунлоадс», «телеграм», «WhatsApp», «Viber»,
«Claude» — только для меток, у которых есть хотя бы один файл. Файлы с меткой SupraWeed такие кнопки не удаляют
(подтверждение говорит, сколько пропущено), а вместо кнопки удаления у них замок: это шаблоны и файлы самой
программы, в них только слова-триггеры, а не ДСК-содержимое.

Кнопки справа в строке запуска (как в VS Code) ставят таблицу файлов под таблицей проверок или рядом с ней.
Выбор сохраняется: в SUSpector.ini как `layout=bottom|right`, в comp-info.ini как `securityLayout`;
для скриншотов есть `--layout right`.

Найденный документ можно удалить кнопкой-корзиной в последнем столбце таблицы файлов (или клавишей Delete) после подтверждения.
Удаление безвозвратное, мимо корзины Windows: проверка ищет документы и в корзине. Файл, найденный в корзине (`$R…`),
удаляется вместе со своей записью `$I…`. Итог проверки показывает число удалённых файлов; когда удалены все найденные,
проверка становится предупреждением с просьбой запустить её снова (в списке не больше 200 совпадений).

## Сборка

```bat
tools\build.BAT
```

Скрипт создаёт в папке `bin\` (не в Git) независимые файлы (у каждого своя версия):

- `comp-info.exe` — полный внутренний тулбокс;
- `SUSpector.exe` — отдельное окно для пользователей (`app\wpf\SUSpector`, WPF; страница — `app\wpf\Pages\SecurityView`,
  логика найденных файлов — `app\src\SecurityFiles.cs`);
- `youSBee.exe` — серийные номера флешек (YOUSBEE.md).

Компьютеру сборки нужен .NET SDK (WINDOWS_APP.md); пользователю — ничего, кроме Windows.

Иконка SUSpector — `app\suspector.ico`, её делает `tools\make-icon.BAT`: размеры от 96 px — из `app\suspector-source.png` (подозрительный взгляд), до 64 px включительно (панель задач, заголовок окна, мелкие значки) — из `app\suspector-small-source.png` (глаз в треугольнике), у которого скрипт убирает чёрный фон со свечением. Картинка окна «О программе» — `app\suspector.png` из того же исходника.
Проверка вёрстки без показа окна (`--layout bottom|right`, `--about` — «О программе», `--width N`, `--demo` — выдуманные
результаты всех видов и найденные файлы с метками):

```bat
SUSpector.exe --theme light --language ru --screenshot suspector.png 700
```

Поддерживаются языки `uk`, `en`, `ru`; без параметра используется язык Windows. Тема по умолчанию также берётся из Windows.
Язык и тема переключаются в окне «О программе», сразу под картинкой (тема меняется на месте; после смены языка окно перестраивается и «О программе» открывается снова);
почта для связи там — suspector@chagear.top (у youSBee — yousbee@, у Тулбокса — toolbox@chagear.top)
и сохраняются в отдельный `SUSpector.ini`: на съёмном диске (флешке) — рядом с программой, чтобы настройки ездили
вместе с ней и на чужих компьютерах ничего не оставалось; на остальных дисках (рабочий стол, «Загрузки») —
в `%APPDATA%\CHAGEAR\`, чтобы рядом с exe не появлялся лишний файл. `SUSpector.ini`, оставленный рядом с exe
старой версией на несъёмном диске, при первом запуске переносится туда. Логика общая с youSBee — `IniSettings`
в `app/src/IniSettings.cs`. Язык по умолчанию — язык интерфейса Windows:
украинский или русский, для остальных — английский.
Кнопка «О программе» открывает окно в том же виде, что и в comp-info, а тексты — коротко и с иконкой у каждого раздела, как
«Про програму» HashPot и SupraWeed: картинка, версия, одна строка о программе, проверки, подготовка, поиск, «только на этом
компьютере», установка и обновление, клавиши, связь с разработчиком (почта копируется по щелчку, сайт), а также язык и тема.
SUSpector не входит в архив обновления основного тулбокса: его можно передавать пользователю как один самостоятельный файл.

## Слова-триггеры

Рабочий список слов-триггеров проверки документов администратор правит в веб-интерфейсе Comp Info, на странице
«Слова SUSpector» (`#/trigger-words`, только роль admin): таблица «слово или фраза — приоритет» (3 высокий, 2 средний,
1 низкий), повторы и недопустимые строки подсвечиваются. Облако хранит список текстом в формате ниже, таблица — только его
редактор. Новая версия программы для этого не нужна: SUSpector
перед каждой проверкой документов спрашивает публичный `https://chagear.top/api/suspector/trigger-words`
(ждёт не дольше 5 с) и сохраняет ответ в `SUSpector-words.json` рядом с `SUSpector.ini`. Без интернета берётся
этот сохранённый список, а если его нет, то встроенный `app\trigger-words.txt` (`tools\build.BAT` встраивает файл в программу).
Если в облаке список не сохранён (ответ 404), SUSpector работает со встроенным списком, а сохранённую копию удаляет.
Откуда взят список, видно в подсказке галочки «Сканировать документы» после проверки.

Формат у облачного и встроенного списков одинаковый (`app\src\TriggerWords.cs`, на странице и в Worker —
`cloud\public\js\trigger-words-logic.js`):

- одно слово или фраза в строке, регистр не важен; `#` начинает комментарий;
- `[высокий]`, `[средний]`, `[низкий]` начинают уровень важности (можно по-украински и по-английски); слова до первого уровня
  считаются средними;
- пробел во фразе совпадает с любыми пробелами или их отсутствием: «т. в. о.» находит и «т.в.о.»;
- если слова перекрываются (ДСК и ДСК-ЕП, штат и штатка), засчитывается более длинное.

Найденные файлы упорядочены по важности: сначала по самому важному найденному слову, затем по сумме
«вес × число совпадений» (высокий 3, средний 2, низкий 1). Если файлов больше 200, в списке остаются 200 самых важных.
Число совпадений в таблице показано цветной меткой: высокий уровень красный, средний жёлтый, низкий серый.
В подсказке к метке — уровень и найденные слова.

## Обновления

Для SUSpector собирается отдельный архив `dist\SUSpector-<версия>.zip`, содержащий только `SUSpector.exe` и `manifest.json`.
GitHub Actions публикует его независимо от внутреннего пакета Comp Info по собственному тегу `suspector-vВЕРСИЯ`;
версия SUSpector своя — `app/SUSpector.version` (поднимает `tools\update-version.BAT suspector`), см. [PROGRAM_UPDATE.md](PROGRAM_UPDATE.md).
Публичный API `/api/suspector` отдаёт только метаданные, этот архив и слова-триггеры (без автора правки); ключ Comp Info пользователю не нужен,
а получить через него основную программу или данные базы невозможно.

Кнопка «Обновление» в нижней панели проверяет `/api/suspector/latest`, скачивает архив во временную папку Windows,
сверяет SHA-256 архива и файла с `manifest.json` и заменяет именно запущенный exe, даже если браузер сохранил его
как `SUSpector (1).exe`. Старый файл остаётся рядом как `<имя>.exe.old` и удаляется при следующем запуске.

## Страница скачивания

Пользователям даётся ссылка https://chagear.top/suspector/ — публичная страница основного сайта
(проект `chagear-site`, папка `public/suspector/`) с описанием программы и кнопкой «Завантажити SUSpector.exe».
Прямая ссылка на программу — https://chagear.top/download/SUSpector.exe (как у HashPot). Поддомен comp-info.chagear.top —
только для веб-интерфейса Comp Info: Worker основного сайта (`chagear-site/worker.js`) передаёт `/download/SUSpector.exe`
и `/api/suspector/*` в Worker Comp Info через service binding. Кнопка «Обновление» SUSpector с версии после 2026.11.12.6
спрашивает `https://chagear.top/api/suspector`; старые копии спрашивают comp-info.chagear.top, это тоже работает.
Кнопка ведёт на `/api/suspector/download`: Worker распаковывает из текущего архива сам `SUSpector.exe`
и отдаёт его как файл, версию страница берёт из `/api/suspector/latest` того же домена.

В веб-интерфейсе администратора раздел «Версии программ» показывает версии Comp Info и SUSpector отдельно;
у SUSpector, как и у Comp Info, можно сделать текущей предыдущую версию — её будут скачивать со страницы
и её предложит кнопка «Обновление».

## Cloudflare Access

Пути `/api/suspector/*` (метаданные, архив, exe и слова-триггеры) и `/api/suspector-release` (публикация из GitHub Actions)
должны быть открыты без входа, как `/api/client/*` и `/api/release`; иначе Access отвечает перенаправлением на страницу входа.
Страница скачивания на основном домене, Access её не касается.
