# Проверка установки ESET

При сборе информации в JSON записывается поле `esetInstalled`:

- `true` — установлена служба антивируса ESET `ekrn`, включая остановленную службу;
- `false` — служба отсутствует;
- `null` — старые данные, проверка ещё не выполнялась.

Отсутствующее поле в старых JSON при просмотре и экспорте считается `null`.
Просмотр добавляет его в объект в памяти; при последующем сохранении записи
оно попадёт в JSON. Массовая перезапись старых файлов не требуется.
При повторном сборе появление результата проверки считается изменением.
CSV содержит колонку `esetInstalled`: `True`, `False` либо пустую ячейку.

Проверяется факт наличия службы, а не активность защиты, лицензия или обновления.
Один ESET Management Agent не считается установленным антивирусом.
Ошибка запроса служб прерывает сбор без записи ложного `false`.

Служба `ekrn` описана в [документации ESET](https://support.eset.com/de/kb60-eset-kernel-dienst-startet-nicht).

Проверки: `powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/eset-info.tests.ps1`.
