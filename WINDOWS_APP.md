# Оконная версия (comp-info.exe)

Программа переехала из консоли (PowerShell) в обычное окно Windows (WinForms на C#), чтобы ей было проще
пользоваться без знания клавиш консольного меню. Все разделы консольного меню перенесены:

| Раздел | Что внутри |
|---|---|
| Сбор информации | таблица «сейчас / в базе», изменения подсвечены, комментарий, сохранение |
| Настройка сети | корпус, сегмент, адаптер, последний октет или DHCP; сводка перед применением |
| Имя компьютера, Домен | IF / FR, транслитерация, проверка имени, учётные данные, проверка после перезагрузки |
| Быстрый ping | свой IP, шлюз, DNS, домен или интернет, остановка на первом сбое |
| База устройств | поиск, сортировка, карточка компьютера с комментарием, экспорт в CSV |
| USB-накопители | серийные номера, кнопка «Копировать» в строке, автообновление при подключении |
| Синхронизация | ключ доступа, отправка и загрузка, разбор конфликтов по полям, удалённые в облаке записи |
| Обновление | версия в облаке, «Что нового», установка с резервной копией, перезапуск |
| О программе | версия, назначение, связь с разработчиком |

Диагностика консоли (эмодзи, скорость отрисовки) в окне не нужна. Консольная версия пока остаётся рядом:
её используют флешки, на которые ещё не пришёл `comp-info.exe` ([PROGRAM_UPDATE.md](PROGRAM_UPDATE.md)).
`comp-info-menu.BAT` открывает оконную версию, если `comp-info.exe` лежит рядом, иначе консольное меню.

## Оформление, язык, клавиши

Внизу меню — переключатели темы (светлая, как в Windows — по умолчанию, тёмная) и языка (украинский, английский,
русский). Пока язык не выбран, берётся язык Windows (украинский или русский, иначе английский). При смене темы
или языка окно строится заново. Сообщения, которые присылает само облако, остаются на русском.

Цвета и элементы повторяют веб-интерфейс (`cloud/public/app.css`): та же палитра светлой и тёмной темы
(`Theme.Apply`), синий акцент, скруглённые кнопки, метки-«таблетки» ESET и статуса облака, моноширинные IP
и серийные номера, подсветка имён не по правилам (жёлтым), повторов (красным) и свежих сборов (зелёным).
При изменении палитры веба стоит поменять и `Theme.Apply`.

Тексты интерфейса — русские строки в коде, обёрнутые в `L.T(...)` / `L.F(...)`; их украинские и английские
версии лежат в `app\src\Strings.cs`. Проверка `app\tests` не даст собрать программу, если у какой-то строки
нет перевода или в переводе потеряны пробелы по краям и подстановки `{0}`.

Клавиши: `Ctrl+1…9` — разделы меню, `Ctrl+0` — «О программе», `Ctrl+Tab` / `Ctrl+PageDown` — следующий раздел;
`F5` — обновить или проверить заново, `Ctrl+S` — сохранить сбор, `Ctrl+F` — поиск в базе (стрелки и `Enter` —
по таблице), `Ctrl+E` — экспорт в CSV, `Ctrl+Enter` — применить настройки сети, имени или домена.

Иконка — `app\icon-source.png`; `tools\make-icon.BAT` делает из неё `app\app.ico` (в размерах до 32 px — простая
шестерёнка без лица, она рисуется в `tools\MakeIcon.cs`), `app\brand.png` (та же шестерёнка в шапке окна)
и `app\face.png` (картинка в «О программе»). При русском интерфейсе «О программе» показывает другую картинку —
`app\face-ru.png`, её тот же скрипт делает из `app\face-ru-source.png`.

## comp-info.ini

Настройки этой копии программы, рядом с ней (на флешке), обычный текст — можно править вручную:

```ini
[settings]
theme=system          ; system, light, dark
language=system       ; system, uk, en, ru
domainUser=CORP\admin ; только если в разделе «Домен» отмечено «Запомнить в comp-info.ini»
domainPassword=b64:…
```

Доменный пароль хранится только по галочке «Запомнить» и лишь замаскированным (base64): флешка ходит
по разным компьютерам и пользователям, поэтому шифрование Windows, привязанное к одному из них, не подходит.
Кто получит такую флешку, получит и эту учётную запись. Пароль локального администратора не сохраняется никогда.
Файл исключён из Git. Первые сборки хранили тему в `app-settings.json` — она переносится автоматически.
## Совместимость с консольной версией

Обе версии читают и пишут одни и те же файлы: `data\*.json`, `cloud-state.json`, `cloud-config.json`,
`cloud-key.txt`, `network-profiles.json`, `exports\*.csv`, `.update\`. Поэтому:

- JSON читается и пишется тем же `JavaScriptSerializer`, что использует Windows PowerShell 5.1
  в `ConvertFrom-Json` / `ConvertTo-Json`: одинаковые числа и экранирование символов;
- контрольная сумма записи (`hash` в `cloud-state.json`, по ней определяется статус «В облаке» / «Изменено»)
  считается так же, как `Get-RecordHash`: эталонные суммы от PowerShell лежат в `app\tests\hash-expected.txt`;
- CSV совпадает с `export-comp-info.ps1` байт в байт (эталон `app\tests\export-expected.csv`);
- правила имён (`ConvertTo-ComputerDesignation`, `Get-SuggestedComputerName`, `Get-ComputerNameIssue`) сверены с PowerShell;
- синхронизация повторяет алгоритм `cloud-client.ps1` и проверена на поддельном облаке в тестах
  (новые записи, конфликт с выбором по полям, удаление в облаке, восстановление, дубликаты, идентификаторы с точкой в конце);
- запись о незавершённом изменении имени или домена (реестр `ComputerInventoryCollector\PendingChange`) общая.

Отличие: IP-адрес при сборе берётся с работающего подключения. Консольная версия могла взять адрес
отключённого адаптера, если он шёл в списке первым.

Изменения системы (адрес сети, `Add-Computer`, `Remove-Computer`, `Rename-Computer`, проверка домена)
выполняются теми же командами Windows PowerShell, что и в консольной версии, в скрытом процессе:
их поведение уже проверено. Пароли передаются ему через стандартный ввод, не через командную строку.
Правила имён и домен подразделения заданы в `ComputerPolicy` (`app\src\SystemChanges.cs`), как в `computer-policy.ps1`.

## Права администратора

`comp-info.exe` запускается без прав администратора. Разделы, которые меняют систему, отмечены в меню щитом:

- «Настройка сети» запрашивает права (окно UAC) только для самой команды настройки;
- «Имя компьютера» и «Домен» перезапускают программу с правами администратора на этом же разделе:
  учётные данные остаются внутри одного процесса.

## Сборка

Ничего устанавливать не нужно: используется компилятор C#, который входит в Windows (.NET Framework 4.8).

```bat
tools\build.BAT
```

Результат — `comp-info.exe` в корне (рядом с `data\`), затем запускаются проверки `app\tests`.
Версия берётся из `console-ui.ps1`, чтобы обе версии показывали один номер выпуска.
Синтаксис ограничен C# 5 (так умеет встроенный компилятор): без `$"..."`, `?.`, `nameof` и т. п.
Сборка явно указывает .NET Framework 4.8: без этого .NET включает режим совместимости с 4.0,
в котором, например, адреса теряют точку в конце идентификатора записи.

- `app\src\` — исходники: ядро (`Json`, `Store`, `Identity`, `Machine`, `Network`, `Export`, `Collector`, `Cloud`,
  `Shell`, `SystemChanges`) и окна;
- `app\tests\` — проверки, поддельное облако и эталоны от PowerShell.

Для проверки вёрстки: `comp-info.exe [--theme light|dark] --screenshot <раздел> <файл.png> [мс]` открывает раздел
за пределами экрана и сохраняет снимок окна (разделы: `collect`, `lan`, `name`, `domain`, `ping`, `database`, `usb`,
`sync`, `update`, `about`; для `database` и `sync` дополнительно сохраняются карточка и диалоги).
Переменная `COMPINFO_UI_PREVIEW=1` показывает форму имени и домена без прав администратора (само изменение их всё равно проверяет).
`obj\tests.exe --check-data <папка>` сверяет статусы настоящей базы с `cloud-state.json`.
