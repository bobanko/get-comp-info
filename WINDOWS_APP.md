# Оконная версия (comp-info.exe)

Программа переезжает из консоли (PowerShell) в обычное окно Windows (WinForms на C#).
Цель — чтобы ей было проще пользоваться без знания клавиш консольного меню.

## Состояние переезда

| Раздел | Статус |
|---|---|
| Сбор информации о компьютере | в окне |
| База устройств (просмотр, карточка, комментарий) | в окне |
| Экспорт в CSV | в окне (кнопка в «Базе устройств») |
| USB-накопители | в окне |
| Быстрый ping | в окне |
| Синхронизация с облаком | пока в консоли (кнопка «Открыть в консоли») |
| Настройка сети (LAN) | пока в консоли |
| Имя компьютера, домен | пока в консоли |
| Обновление программы | пока в консоли; `comp-info.exe` ещё не входит в выпуск |

Разделы, которые ещё не перенесены, открывают прежний PS1-сценарий в отдельном окне PowerShell.
Пока переезд не закончен, консольная версия остаётся на флешке рядом и работает с теми же файлами.

## Совместимость с консольной версией

Обе версии читают и пишут одни и те же файлы: `data\*.json`, `cloud-state.json`, `cloud-config.json`,
`network-profiles.json`, `exports\*.csv`. Поэтому:

- JSON читается и пишется тем же `JavaScriptSerializer`, что использует Windows PowerShell 5.1
  в `ConvertFrom-Json` / `ConvertTo-Json`: одинаковые числа и экранирование символов;
- контрольная сумма записи (`hash` в `cloud-state.json`, по ней определяется статус «В облаке» / «Изменено»)
  считается так же, как `Get-RecordHash`: эталонные суммы от PowerShell лежат в `app\tests\hash-expected.txt`;
- CSV совпадает с `export-comp-info.ps1` байт в байт (эталон `app\tests\export-expected.csv`);
- запись компьютера сохраняется с теми же полями в том же порядке, поиск своей записи — по тем же правилам
  (`computer-identity.ps1`).

Отличие: IP-адрес при сборе берётся с работающего подключения. Консольная версия могла взять адрес
отключённого адаптера, если он шёл в списке первым.

## Права администратора

`comp-info.exe` запускается без прав администратора. Разделы, которые меняют систему (сеть, имя, домен),
отмечены в меню значком щита и запрашивают права (окно UAC) только для самого изменения.

## Сборка

Ничего устанавливать не нужно: используется компилятор C#, который входит в Windows (.NET Framework 4.8).

```bat
tools\build.BAT
```

Результат — `comp-info.exe` в корне (рядом с `data\`), затем запускаются проверки `app\tests`.
Версия берётся из `console-ui.ps1`, чтобы обе версии показывали один номер выпуска.
Синтаксис ограничен C# 5 (так умеет встроенный компилятор): без `$"..."`, `?.`, `nameof` и т. п.

- `app\src\` — исходники: ядро (`Json`, `Store`, `Identity`, `Machine`, `Network`, `Export`, `Collector`) и окна;
- `app\tests\` — проверки и эталоны от PowerShell;
- `app\app.ico` — иконка, собирается `tools\make-icon.BAT` из иконки веб-интерфейса.

Для проверки вёрстки: `comp-info.exe --screenshot <раздел> <файл.png> [мс]` открывает раздел за пределами
экрана и сохраняет снимок окна (разделы: `collect`, `database`, `usb`, `ping`, `lan`, `name`, `domain`, `sync`, `update`).
`obj\tests.exe --check-data <папка>` сверяет статусы настоящей базы с `cloud-state.json`.
