# Синхронизация с флешкой

Запускай `sync-usb.BAT` **из проекта на основном компьютере**. Введи полный путь к папке программы на флешке, например `E:\get-comp-info`. Если папки нет, скрипт создаст её. Букву диска проверяй при подключении флешки.

Можно передать путь сразу:

```powershell
.\sync-usb.ps1 -UsbPath 'E:\get-comp-info'
```

Перед запуском закрой сборщик и просмотрщик на обоих устройствах. Дождись завершения синхронизации перед извлечением флешки.

Сначала скрипт копирует новые `data\*.json` с флешки на компьютер. Совпадающие файлы пропускает. Если содержимое различается, локальная запись остаётся на месте, а версия с флешки сохраняется в `sync-conflicts\<имя записи>\<SHA256>.json`. Повторный запуск не создаёт дополнительные копии той же версии. Конфликтующие записи нужно сравнить и вручную выбрать нужное содержимое для локального файла в `data`.

Затем скрипт обновляет корневые `.ps1`, `.bat` и `.cmd` файлы программы на флешке, включая `sync-usb.ps1` и `sync-usb.BAT`. Запускать синхронизацию по-прежнему нужно из проекта на основном компьютере: папка запущенного скрипта считается источником кода и получателем данных. Данные с компьютера на флешку не копируются. `.git`, документация и другие папки не переносятся. Устаревшие файлы на флешке не удаляются.

Каждая копия проверяется по SHA256. При ошибке скрипт останавливается с кодом 1; уже выполненные копирования сохраняются, после устранения причины можно запустить его повторно. Конфликты выводятся как предупреждения и не мешают обновлению программы.

Git и интернет для синхронизации не нужны. Существующий пункт обновления через GitHub в меню для этого процесса не используется.
