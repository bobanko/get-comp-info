# FlashStashBee

`FlashStashBee.exe` — фоновая утилита в трее: как только в компьютер вставляют флешку, её содержимое
копируется в папку на диске. Значок в трее — фиолетовый контур флешки, состояние показывает значок
поверх него в углу. Всплывающих уведомлений нет. Окна по умолчанию нет — только значок; настройки
открываются из его меню. Права администратора и интернет не нужны, в сеть ничего не отправляется.

WPF на .NET Framework 4.8, как youSBee и SUSpector (WINDOWS_APP.md). Значок в трее —
`System.Windows.Forms.NotifyIcon` (у WPF своего значка в трее нет), значки рисуются из кода
(`TrayIcons.cs`), а меню — WPF ContextMenu в стиле программы (`TrayMenu.xaml`). Копирование —
управляемое, в фоновом потоке, без дочерних процессов (`CopyJob.cs`). Интерфейс трёхъязычный
(українська / English / русский), как у youSBee.

## Значок в трее

Фиолетовый контур флешки по образцу стандартного значка Windows для съёмного диска (на 20 px: широкий разъём
9 px с двумя точками-отверстиями над корпусом 11 px, углы прямые), а в правом нижнем углу — значок состояния,
без кружка-подложки: вокруг него вырезан прозрачный зазор, который разрывает контур флешки. Всё рисуется
целыми пикселями (прямоугольниками, без сглаживания) в настоящем размере значка трея (`SM_CXSMICON`, с учётом
DPI), чтобы система не масштабировала его и края оставались чёткими.

| Значок в углу           | Состояние                                             |
|-------------------------|-------------------------------------------------------|
| ⋯ три серые точки       | ожидание флешки                                       |
| ↓ зелёная стрелка, мигает | идёт копирование (скачивание бэкапа)                |
| ❚❚ оранжевый            | пауза                                                 |
| «!» красный             | ошибка или том пропущен (слишком большой)             |
| число зелёное           | готово; цифра — сколько флешек обработано за сеанс     |

При наведении подсказка показывает, что копируется, и процент (`Копирую: KINGSTON — 42%`); в ZIP-режиме после
копирования идёт отдельный этап `Упаковываю в ZIP: KINGSTON — 42%`. Конец копирования программа узнаёт сразу
(событие от потока копирования), поэтому значок перестаёт мигать в тот же момент.

Меню (правый клик) — в стиле меню Windows 11 и темы программы: только «Настройки» (шестерёнка), «Пауза»
(две полоски; на паузе — «Возобновить» с треугольником), «Выход».
**Двойной клик по значку закрывает программу.** Открыть папку с бэкапами и чёрный список — в окне настроек.

## Куда и что копирует

Одна флешка — одна папка, по серийному номеру USB-устройства: `Метка [серийник]`. Повторная вставка той
же флешки **не создаёт новый бэкап**: копируются только новые и изменённые файлы в ту же папку, а что
добавилось — дописывается в журнал `_журнал.txt` внутри неё. Если серийника нет, папка называется по метке
(`Метка [vol]`).

- Копируются только обычные флешки (съёмные тома), вставленные **после** запуска утилиты; уже стоявшие при
  старте не трогаются. Внешние HDD/SSD не копируются.
- Инкрементально: файл копируется, только если его ещё нет в папке или он изменился (размер/дата).
- Служебные папки (`System Volume Information`, `$RECYCLE.BIN`, `Found.000`) и стыки/ссылки пропускаются.
- Файлы больше лимита не копируются; по желанию вместо них кладётся пустышка `имя (пропущен).txt`
  с именем, размером и датой оригинала — видно, что там было.
- Фильтр типов файлов работает в двух режимах: «копировать только эти типы» или (галочка «Наоборот»)
  «копировать всё, кроме этих типов».
- **Чёрный список по серийнику** — в окне настроек, раздел «Не копировать эти флешки»: вставленную флешку
  можно добавить из списка, ненужную запись — убрать. Флешки из списка не копируются; если такая флешка как раз
  копируется, копирование останавливается.
- **ZIP**: с включённой упаковкой каждая флешка — один `Метка [серийник].zip` **без сжатия** (store: смысл в одном
  файле бэкапа, а не в экономии места), а папка после упаковки удаляется. Поэтому в ZIP-режиме каждая вставка —
  полный снимок, а не досинхронизация.

## Настройки

Окно «Настройки…» (оформление общее с другими программами — `StandaloneWindow`; тема и язык в «О программе»).
Высота окна подстраивается под содержимое, размер не меняется. У каждого раздела слева иконка, как в «О программе».
Рядом с папкой назначения — «Обзор…» и «Открыть» (открывает папку с бэкапами в Проводнике). Лимиты размера
включаются галочкой в той же строке (вместо прежнего «0 — без ограничения»); числовые поля принимают только
цифры, значение можно менять стрелками ▲▼ или клавишами ↑↓.
Хранятся в `flashstashbee.ini` рядом с программой на флешке, иначе в `%APPDATA%\CHAGEAR\` (как у youSBee).

| Настройка                              | Ключ ini            | По умолчанию          |
|----------------------------------------|---------------------|-----------------------|
| Папка назначения                       | `baseDir`           | `%TEMP%\FlashStashBee` |
| Не копировать флешки, где занято больше | `maxSizeOn`, `maxSizeGb` | `on`, `64` ГБ   |
| Не копировать файлы больше             | `maxFileOn`, `maxFileMb` | `on`, `200` МБ  |
| Вместо них — пустышка                  | `stubs`             | `on`                  |
| Типы файлов                            | `extensions`        | пусто (все файлы)     |
| Наоборот: всё, кроме этих типов        | `extensionsExclude` | `off`                 |
| Упаковывать в ZIP (без сжатия)         | `zip`               | `off`                 |
| Запускать при входе в Windows  | ключ `Run` в реестре HKCU | выкл.        |
| Не копировать эти флешки       | `excludeSerials` | пусто                 |

## Сборка

`tools\build.BAT flashstashbee` (или без аргументов — вместе с остальными) собирает `bin\FlashStashBee.exe`
из `app\wpf\FlashStashBee` (нужен .NET SDK на компьютере сборки). Версия своя — `app\FlashStashBee.version`,
поднимает `tools\update-version.BAT flashstashbee`. Ядро, обвязка и «О программе» общие с youSBee.

Значок: `app\flashstashbee.ico` и картинка «О программе» `app\flashstashbee.png` рисует
`tools\make-flashstashbee-icon.ps1` (фиолетовый контур флешки в духе стандартного значка съёмного диска
Windows, без фона; мелкие размеры — без сглаживания, чтобы были чёткими в панели задач, 256 — сглаженный
для «О программе»). Значок в трее рисуется из кода (`TrayIcons.cs`) тем же контуром. Чтобы поменять —
поправить скрипт и запустить его, затем `tools\build.BAT flashstashbee`.

Проверка вёрстки окна настроек без трея:

```bat
FlashStashBee.exe --theme light --language ru --screenshot settings.png 2000
FlashStashBee.exe --about --screenshot about.png 2000
```

## Антивирус и SmartScreen

Фоновое копирование со вставленных флешек — поведение, на которое реагируют эвристики (так ведут себя
USB-стилеры). Сделать утилиту «невидимой» для антивируса нельзя и не нужно; убрать ложные срабатывания
для своей программы на своих машинах можно легально:

1. **Подпись кода.** Подписанный релиз (SignPath Foundation, [CODE_SIGNING.md](CODE_SIGNING.md)), собранный
   на GitHub Actions, с чистыми метаданными (Company/Product/Version их ставит `build.BAT`) — главный способ
   снять и SmartScreen, и репутационные движки. Если заводить облако/релиз, как у youSBee, тег —
   `flashstashbee-vВЕРСИЯ` (workflow ещё нет).
2. **Исключение в Defender на своей машине** — `tools\flashstashbee\allow-in-defender.ps1` (нужен админ;
   `-Remove` убирает). Для стороннего антивируса — добавить исключение в нём.
3. Утилита намеренно «не подозрительная»: видимый значок в трее, без упаковки/обфускации, манифест
   `asInvoker`, запуск из обычной папки.
